Politique de confidentialité

Dernière mise à jour : Mai 2026

Glyko respecte votre vie privée. Vos données de santé ne sont jamais vendues ni partagées avec des tiers à des fins publicitaires.

1. Qui sommes-nous ?

Glyko est une application mobile de suivi nutritionnel éditée par [VOTRE NOM / SOCIÉTÉ], dont le siège est situé à [ADRESSE], France.

Contact : privacy@glyko.fr

2. Données collectées

Glyko collecte uniquement les données nécessaires au fonctionnement de l'application :

  • Données de compte : adresse email, prénom (pour la création de compte)
  • Données de santé : journal alimentaire, profil diabétique, objectifs glucidiques, ratio insuline indicatif
  • Données techniques : logs d'erreurs anonymisés, version de l'application
  • Données d'abonnement : statut Premium géré par Apple/Google/RevenueCat
⚕️ Les données de santé (journal alimentaire, profil diabétique) sont des données sensibles au sens de l'article 9 du RGPD. Leur traitement est soumis à votre consentement explicite, recueilli lors de l'installation de l'application.

3. Base légale du traitement

  • Données de compte : exécution du contrat (Art. 6.1.b RGPD)
  • Données de santé : consentement explicite (Art. 9.2.a RGPD)
  • Données d'abonnement : exécution du contrat + obligation légale comptable
  • Logs techniques : intérêt légitime (Art. 6.1.f RGPD)

4. Durée de conservation

  • Données de compte et de santé : jusqu'à la suppression du compte
  • Données de facturation : 10 ans (obligation légale)
  • Logs techniques : 90 jours glissants

5. Partage des données

Vos données ne sont jamais vendues. Elles peuvent être partagées uniquement avec nos sous-traitants techniques :

  • Supabase (base de données) — hébergé en France (Paris, EU)
  • Railway (serveur API) — hébergé en EU
  • RevenueCat (abonnements) — USA, couvert par SCC
  • Apple / Google (distribution et paiements) — USA, couvert par SCC

6. Vos droits (RGPD)

Conformément au RGPD, vous disposez des droits suivants :

  • Accès : obtenir une copie de vos données
  • Rectification : corriger vos données inexactes
  • Suppression : supprimer votre compte et toutes vos données depuis l'app (Paramètres → Supprimer mon compte)
  • Portabilité : recevoir vos données dans un format lisible
  • Opposition : vous opposer à certains traitements
  • Retrait du consentement : retirer votre consentement aux données de santé à tout moment

Pour exercer ces droits : privacy@glyko.fr

Vous pouvez également déposer une réclamation auprès de la CNIL.

7. Sécurité

  • Chiffrement TLS pour toutes les communications
  • Mots de passe hachés (bcrypt)
  • Authentification JWT avec expiration automatique
  • Row Level Security — chaque utilisateur accède uniquement à ses propres données
  • Hébergement en Europe (Paris)

8. Données des enfants

Glyko est réservé aux personnes âgées de 16 ans et plus. Nous ne collectons pas sciemment de données d'enfants de moins de 16 ans.

9. Modifications

Cette politique peut être mise à jour. En cas de modification substantielle, vous serez informé dans l'application.

10. Contact

Pour toute question relative à cette politique : privacy@glyko.fr
